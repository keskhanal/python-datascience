# Lesson 05 — OOP: Classes & Objects

**Day 5** · Notebook: [`classes_and_objects.ipynb`](classes_and_objects.ipynb)

The first half of object-oriented programming: bundling data and behaviour together.
Opens with a revision of Lesson 04.

## Topics

- Why OOP — the same problem written with functions vs. with a class
- `class` and creating objects (instances)
- The `__init__` constructor and `self`
- Instance attributes
- Methods
- A real-world example modelled as a class
