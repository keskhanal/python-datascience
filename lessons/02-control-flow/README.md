# Lesson 02 — Control Flow

**Day 2** · Notebook: [`control_flow.ipynb`](control_flow.ipynb)

Making programs branch and repeat. Opens with a revision of Lesson 01.

## Topics

- `if`, `if-else`, `if-elif-else`
- Nested `if`
- `match` / `case`
- `while` loops (and how to avoid infinite loops)
- `for` loops and `range()`
- Looping over a string
- `break`, `continue`, `pass`

## Exercises

1. Grade calculator — map marks to grades A/B/C/D.
2. Check whether a person is eligible to vote (age and nationality).
3. Check whether a number is odd or even.
4. Print `python` 100 times with a loop.
