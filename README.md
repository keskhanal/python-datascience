# Data Science Course

This repository contains teaching materials and sample Python code for a data science course.

## Structure

- `file_handling/` - notebooks and sample text files for file handling exercises.
- `notebooks/` - Jupyter notebooks for Python basics and advanced topics.
- `python_modules/` - example Python modules and a simple package.

## Getting Started

1. Clone the repository:

```bash
git clone <repository-url>
cd datascience-course
```

2. (Optional) Create and activate a Python virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

5. Open a notebook:

- Use VS Code with the Jupyter extension, or
- Run `jupyter notebook` from the repository root and open notebooks in the browser.
