# Interview Prep

**Notebook:** [`python_interview.ipynb`](python_interview.ipynb)

Questions and coding problems that come up in Python interviews. Work through these after
finishing the lessons.

## Concept Questions

- Shallow copy vs. deep copy (`copy.copy()` vs. `copy.deepcopy()`)
- `is` vs. `==` — identity vs. equality

## Coding Problems

1. Find the largest number in a list **without** using `max()`.
2. Count character frequency in a word.
3. Find the second-largest number in a list.
